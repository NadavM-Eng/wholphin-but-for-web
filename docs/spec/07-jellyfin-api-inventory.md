# 07 - Jellyfin API inventory (every server call Wholphin makes)

Source: `reference/wholphin/app/src/main/java/com/github/damontecres/wholphin/` (abbrev. `W/`). Kotlin SDK `org.jellyfin.sdk` **1.9.4** (`gradle/libs.versions.toml:32`); SDK extension accessors imported from `org.jellyfin.sdk.api.client.extensions.*` on `ApiClient`.

How to read the tables
- **SDK method** = Kotlin accessor as written in the source (note: in SDK 1.9 several REST controllers are merged into one accessor: `libraryApi` covers `Items`, `UserLibrary` and `Library` controllers; `userDataApi` covers `UserLibrary`/`PlaystateController` mark/favorite calls; `systemApi.logFile` is the `ClientLog` controller). The TypeScript `@jellyfin/sdk` (checked against `node_modules/@jellyfin/sdk/lib/utils/api/*.d.ts`) has merged the controllers the same way as Kotlin 1.9, and several accessor names are singular; there is **no** `getItemsApi`, `getUserLibraryApi`, `getPlaystateApi`, `getTvShowsApi`, `getQuickConnectApi`, `getClientLogApi` or `getUniversalAudioApi`. Real accessors from `@jellyfin/sdk/lib/utils/api`: `getLibraryApi` (Items, UserLibrary, Library, `/UserItems/Resume`, `/Items/Latest`, Similar, Ancestors, Intros, Trailers, ThemeSongs, Download), `getUserDataApi` (`/UserPlayedItems`, `/UserFavoriteItems`), `getShowApi` (NextUp, Episodes, Seasons), `getUserViewApi`, `getSuggestionApi`, `getYearApi`, `getVideoApi`, `getAudioApi` (universal), `getAuthenticationApi` (incl. QuickConnect), `getTrickPlayApi`, `getSystemApi`, `getSessionApi`, `getPlaylistApi`, `getInstantMixApi`, `getLyricApi`, `getLiveTvApi`, `getGenreApi`, `getStudioApi`, `getPersonApi`, `getArtistApi`, `getFilterApi`, `getLocalizationApi`, `getDisplayPreferenceApi`, `getImageApi`, `getMediaInfoApi`, `getMediaSegmentApi`, `getSubtitleApi`, `getUserApi` - - use the **REST endpoint** column as the contract; REST paths below are the 10.10/10.11 server routes (where 10.10 and 10.11 differ the 10.11 route is given and the 10.10 legacy route noted).
- **Where** = `path:line` relative to `W/`, first-listed is the primary call-site.
- All calls are authenticated with header `Authorization: MediaBrowser Client="Wholphin", Device="..", DeviceId="..", Version="..", Token=".."` (see 06 doc section 5.9) except those marked *public*. User scoping: many (not all) calls pass `userId = current user id` (query) explicitly; the SDK does not infer it. `userId` is optional on `getItem`, mark/unmark played/favorite, `getNextUp(seriesId)`, `getLocalTrailers`/`getSpecialFeatures`/`getThemeSongs` and `getAdditionalPart`, and Android omits it there (the server takes it from the token) - e.g. services/FavoriteWatchManager.kt:27-40, services/DatePlayedService.kt, services/PlaylistCreator.kt.
- `Pager` = `ApiRequestPager`: pages of **100** (`DEFAULT_PAGE_SIZE`, W/ui/UiConstants.kt:45; a few use 50) with `startIndex = page*pageSize`, `limit = pageSize`, `enableTotalRecordCount=true` only for the first page; keeps an LRU cache of **8** pages; `countMatching` re-issues the request with `limit=0, enableTotalRecordCount=true` (W/util/ApiRequestPager.kt:40-147).
- Field sets (`fields=` query, W/ui/UiConstants.kt:46-87): `SlimItemFields = [Overview, SortName, MediaSourceCount, CanDelete]`; `ItemRowFields = Slim + PrimaryImageAspectRatio`; `HomeItemFields = [Overview, CanDelete]`; `DetailItemFields = [Overview, Trickplay, SortName, Chapters, MediaSources, MediaSourceCount, CanDelete, PrimaryImageAspectRatio]`; `PhotoItemFields = Detail + [Width, Height]`; `ProgramItemFields = Detail + [ChannelInfo]`.

Version gate (ui/setup/SwitchUserViewModel.kt:301-316; WholphinApplication.kt:124-126): `checkServerVersion` reads `getPublicSystemInfo().version` and returns `UNKNOWN` (no version), `NOT_SUPPORTED` (< `Jellyfin.minimumVersion` from the SDK), `NOT_SUPPORTED_IN_FUTURE` (< `newMinimumServerVersion` = 12.0.0) or `SUPPORTED`. Adding a server by URL (ui/setup/SwitchServerViewModel.kt:189-232) requires the best candidate (first with `score != BAD`) to have a valid UUID `id` and `startupWizardCompleted == true`, otherwise it errors "Server returned invalid response". The `getQuickConnectEnabled` call uses 6 s request/connect/socket timeouts and any failure means `quickConnectEnabled=false` (SwitchUserViewModel.kt:100-135).

Login UI flow (ui/setup/SwitchUserContent.kt:198-300; SwitchUserViewModel.kt:176-258; ui/preferences/QuickConnectDialog.kt:45): if QuickConnect is enabled, the Add-User dialog auto-starts `initiateQuickConnect` and shows the code (state "Waiting for Quick Connect code..." until it arrives); a text button switches to username/password and cancels the QC polling. The first `getQuickConnectState` poll happens 5 s after initiate (`delay(5000)` before every poll). A 401 during QC sets `quickConnectEnabled=false`. Password login maps a 401 to "Invalid username or password"; any other error becomes "Error during login". The Settings QC-authorize dialog accepts exactly 6 digits (trimmed).

SDK-level behaviour: after login `apiClient.update(baseUrl, accessToken)`; all later requests carry the token. Timeouts for ad-hoc API clients: request/connect/socket 6 s (probe), default otherwise.

## 7. Image URLs (`services/ImageUrlService.kt`) — full detail

All image URLs are produced by the SDK `imageApi.getItemImageUrl(...)`, i.e.

```
{baseUrl}/Items/{itemId}/Images/{ImageType}[/{imageIndex}]
    ?fillWidth=<int>&fillHeight=<int>&quality=96&tag=<imageTag>[&format=..][&percentPlayed=..][&unplayedCount=..][&blur=..][&backgroundColor=..][&foregroundLayer=..]
```
Only non-null parameters are emitted. `baseUrl` null/blank -> returns `null` (no image). **No access token** is added (image routes are `AllowAnonymous`; Android also sends the Authorization header through Coil's auth OkHttp client - harmless). ImageType names on the wire: `Primary, Backdrop, Banner, Thumb, Logo, Art, Disc, Box, Screenshot, Menu, Chapter, BoxRear, Profile`.

### 7.1 Parameters
| Param | Default / usage |
|---|---|
| `quality` | **96** (`QUALITY` constant, ImageUrlService.kt:232,284); the low-level overload exposes `quality`, but no caller overrides it. `Person.kt:38,53` call `imageApi.getItemImageUrl(dto.id, PRIMARY, tag=primaryImageTag)` directly -> no quality/size params |
| `fillWidth` / `fillHeight` | Passed only when `> 0` (otherwise dropped). Jellyfin semantics: the server resizes (aspect ratio preserved, no server-side crop) so the result *covers* the given box; the client then applies its own `ContentScale`/object-fit. Callers pass the **pixel size of the card slot**: `dp.roundToPx()` of the card height or width (e.g. poster rows: card height 172dp (`Cards.height2x3`) -> `fillHeight=172*density`; episode cards `Cards.HEIGHT_EPISODE` = 128dp; live-tv cards `HEIGHT_LIVE_TV` = 96dp (ui/UiConstants.kt:93-101); genre/studio cards are **width-driven**: `fillWidth = roundToPx((screenWidthDp - (2*16dp + 3*16dp)) / 4 columns)` (ui/components/GenreCardGrid.kt:274-292, StudioCardGrid.kt:166-184); `BannerCard` passes `fillHeight` only (`fillWidth=null`), `SeasonCard` passes both when specified; chapters `cardHeight` default 120dp -> `fillHeight`; grid cards use `fillWidth = measured cell width px`). `ItemCardImage` gets **no URL at all** only when BOTH `fillWidth` and `fillHeight` are null or <= 0 (one positive dimension is enough; ui/cards/ItemCardImage.kt:69-80). Web equivalent: `Math.round(cssPx * devicePixelRatio)` (round up to a bucket, e.g. multiples of 40/50 px, to improve cache hits) |
| `maxWidth,maxHeight,width,height` | never set by the app (supported by the service signature) |
| `tag` | The image tag from `BaseItemDto.ImageTags[type]` / `BackdropImageTags[0]` / `ParentThumbImageTag` / `ParentLogoImageTag` / `ParentBackdropImageTags[0]` / `SeriesPrimaryImageTag` / `AlbumPrimaryImageTag` / chapter `ImageTag`; used for cache-busting and long cache lifetimes. If no tag is known the URL is still built without `tag` |
| `imageIndex` | Backdrop N (NowPlayingViewModel.kt:265-273, `BackdropImageTags.sorted()` index) and chapter index (ui/cards/ChapterCard.kt:52-59: `imageType=Chapter, imageIndex=chapter.index, tag=chapter.tag`) |
| `format`, `percentPlayed`, `unplayedCount`, `blur`, `backgroundColor`, `foregroundLayer` | exposed but not used by current callers (progress/played badges are drawn client-side) |

### 7.2 Item -> image selection rules (`getItemImageUrl(itemId,itemType,seriesId,useSeriesForPrimary,imageType,imageTags,backdropTags,parentThumbId,parentBackdropId,..., seriesPrimaryTag, parentLogoId, parentLogoTag, parentThumbTag, parentBackdropTags)`, ImageUrlService.kt:26-193)
Let `isEpOrSeason = itemType in {Episode, Season}`.
1. **Logo**: if `seriesId != null && isEpOrSeason` -> `Logo` of the **series** (`itemId=seriesId`, tag = `parentLogoImageTag` only if `parentLogoItemId == seriesId`) else own `Logo` with `imageTags[Logo]`.
2. **Backdrop**: if `seriesId != null && isEpOrSeason` -> series backdrop (tag = `parentBackdropImageTags[0]` if `parentBackdropItemId == seriesId`); else if the item has `BackdropImageTags` -> own backdrop with `backdropTags[0]`; else **null** (no URL).
3. **Thumb**: (a) `useSeriesForPrimary && parentThumbItemId != null && isEpOrSeason` -> parent thumb (`tag=parentThumbImageTag`); (b) else `useSeriesForPrimary && parentBackdropItemId != null && isEpOrSeason` -> parent **Backdrop** with `parentBackdropImageTags[0]`; (c) else `parentThumbItemId != null && itemType == Season && Thumb not in imageTags` -> parent thumb; (d) else `useSeriesForPrimary && parentThumbItemId == null && itemType == Episode && Thumb not in imageTags` -> the episode's own **Primary** (`imageTags[Primary]`); (e) else if `Thumb not in imageTags && backdropTags nonEmpty` -> own **Backdrop** `backdropTags[0]`; (f) else own Thumb with `imageTags[Thumb]`.
4. **Primary / Banner**: (a) `useSeriesForPrimary && seriesId != null && isEpOrSeason` -> series image (`itemId=seriesId`, tag=`seriesPrimaryImageTag` **only when type is Primary**); (b) else `seriesId != null && itemType == Season && imageType not in imageTags` -> series image (same tag rule); (c) else own image with `imageTags[imageType]`.
5. **Everything else** (Art, Disc, Chapter via other overload, ...): own item with `imageTags[imageType]`.
`BaseItem.useSeriesForPrimary` decides whether episode/season cards show the series poster. The `BaseItem` field and its factory default to **false** (data/model/BaseItem.kt:46,349-353); `HomeRowViewOptions.useSeries` defaults to true (data/model/HomeRowConfig.kt:257) and home rows pass it into `BaseItem(dto, useSeries)`; `BannerCard` defaults its own param to true. Items built without the flag (library grids, search, detail pages) do NOT substitute the series poster unless the call site overrides it (explicit `useSeriesForPrimary = true` in ui/components/CollectionFolderList.kt:223 and the PlaybackViewModel media-metadata call, :786-790) - check each call site. `getItemImageUrl(item: BaseItem?, imageType, fillWidth?, fillHeight?, useSeriesForPrimary?)` unpacks the DTO fields listed above (`seriesId, imageTags, parentThumbItemId, parentBackdropItemId, backdropImageTags, seriesPrimaryImageTag, parentLogoItemId, parentLogoImageTag, parentThumbImageTag, parentBackdropImageTags`) and returns `null` for a null item. A per-item `imageUrlOverride` (e.g. Seerr / extras / genre cards built elsewhere) wins in `BannerCard`, `BackdropService` (services/BackdropService.kt:61), `CollectionFolderList` (:223) and `HomePage` (ui/main/HomePage.kt:650,661).

Logo gate (ui/components/TitleOrLogo.kt:90-108): `rememberLogoUrl` uses the series logo for an Episode/Season only if `seriesId != null` AND `parentLogoImageTag != null` (tag sent only when `parentLogoItemId == seriesId`); otherwise it builds an own-logo URL only if `Logo in item.imageTags`; in all other cases there is **no URL** - a web port must not request nonexistent logos. Genre-card images: if the picked item has no backdrop tags the helper returns null.

## 8. Call-flow cheat-sheet (what is called when)

- **App start / auto sign-in**: `GET /Users/Me`, `GET /System/Info/Public` (+ websocket, `POST /Sessions/Capabilities`, plugin `GET /wholphin/public`, home settings load (DisplayPreferences `GET`), `GET /UserViews`, optional `GET /LiveTv/Recordings/Folders`).
- **Home**: per row: Continue Watching = `GET /UserItems/Resume`; Next Up = `GET /Shows/NextUp`; Combined = both merged by a per-item sort key, descending (client merge, services/LatestNextUpService.kt:133-166): resume items use their own `userData.lastPlayedDate`; each Next Up entry gets its key from an extra `GET /Shows/{seriesId}/Episodes?adjacentTo={episodeId}&limit=1` (`userData.lastPlayedDate` of the adjacent episode, `LocalDateTime.MIN` if none, replaced by the Next Up episode's own `premiereDate` if that is later; on `InvalidStatusException` the key is the `premiereDate`, else MIN; services/DatePlayedService.kt:42-120), run at concurrency 3, cached 2 h per (series, episode) and invalidated on mark played; Recently added = `GET /Items/Latest`; Recently released = `GET /Items` (`sortBy=[PremiereDate,SeriesSortName,AiredEpisodeOrder]`, `sortOrder=[Desc,Asc,Desc]`, `maxPremiereDate=now`, `isUnaired=false`, see 2.1); Genres/Studios = `GET /Genres|/Studios` + one `GET /Items` per genre for the cover; Favorites = `GET /Persons?isFavorite=true` for People, `GET /Artists?isFavorite=true` for MusicArtist, otherwise `GET /Items` (`recursive`, `includeItemTypes=[kind]`, `isFavorite=true`) (services/HomeDataService.kt:456-536); Recordings/TvPrograms/TvChannels = LiveTv endpoints; Suggestions = cached ids -> `GET /Items?ids=`; custom endpoint = plugin URL.
- **Detail**: `GET /Items/{id}`, `/Similar`, `/SpecialFeatures`, `/LocalTrailers`, `/ThemeSongs`, `/Shows/{id}/Episodes`, `GET /Items?parentId=&includeItemTypes=Season` (series seasons: `recursive=false`, `sortBy=[IndexNumber]`, page size 20). Series detail also calls `GET /Shows/NextUp?seriesId=`, falling back to `GET /Shows/{id}/Episodes?limit=1` for "Play series" and for PlaylistCreator (ui/detail/series/SeriesViewModel.kt:~311-345,509-520; services/PlaylistCreator.kt:244-258).
- **Play**: `POST /Items/{id}/PlaybackInfo` -> stream URL -> `POST /Sessions/Playing` -> progress every 5 s -> `POST /Sessions/Playing/Stopped`; segments `GET /MediaSegments/{id}`; trickplay tiles on demand.
- **Mark played / favorite**: `/UserPlayedItems`, `/UserFavoriteItems` then re-`GET /Items/{id}` to refresh the card.
